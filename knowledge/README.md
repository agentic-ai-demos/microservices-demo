# Knowledge catalog

bundle for Online Boutique, a twelve-service polyglot storefront: one markdown file per concept, cross-linked, small enough that an agent can
read all of it before deciding where to look.

## How to read it

Every gotcha cites the commit it came from, so you can run `git show` on any claim you doubt.
`catalogify verify` does that mechanically: it resolves each cited commit against the concept
that cites it, checks every symbol named in an interface table against non-test source, and
rejects any invariant asserted with no evidence at all.

## How to correct it — this is the important part

Whatever the generator could not establish from code and history it parked as an
`open_questions` entry rather than inventing an answer. There are **27** of them here. They
are questions no parser can settle: whether a timeout is a contract or an implementation
detail, what happens on partial failure, who owns a component and what the escalation path is.

```bash
catalogify clarify knowledge/
```

That walks a human through the open questions, folds the answers back into the concepts, and
marks each one so later regenerations never overwrite it. **A human answer outranks the
machine's inference permanently.**

Everything else in this directory can be regenerated in minutes. What a person adds here
cannot, and it is the part worth keeping.
